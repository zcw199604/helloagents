# 开发实施阶段转换规则

## 阶段转换规则

```yaml
完成所有动作后:
  - 可选多模型验收在步骤11.5、归档前完成；P0/P1 未闭环时不得迁移
  - 存在方案包时，步骤12 no-clobber 迁移和 history 索引更新成功
  - 自适应无方案包时，成功标准、安全检查和目标验证已完成并保存摘要
  - 步骤13保存输出字段并在 finally 执行 RESET_WORKFLOW_STATE
  - 输出与实际结果匹配的完成总结，开发实施结束

异常情况（测试失败/用户提出问题）:
  阻断性测试失败: 所有模式均阻止归档和成功总结；在已有授权内按步骤7修复并重测，无法安全继续时等待必要决定
  P1 警告性失败: 先在已有授权内修复；仍未解决时默认阻止归档，只有用户明确接受风险后才能按 risk_accepted 交付
  P2 信息性失败: 如实记录影响和剩余限制，可继续后续步骤，不将失败描述为通过
  后续用户消息按路由优先级处理
  取消/终止/不可恢复错误: 保留可恢复文件证据，在 finally 执行 RESET_WORKFLOW_STATE
```
