# 处理路径与门禁

## 处理路径

<complexity_paths>

风险等级只决定当前请求采用的处理深度，不形成跨轮次持久状态；不引入 Light/Heavy 持久模式变量。执行中根据新证据升降风险即可，禁止为了切换路径维护第二套状态机。

### 咨询问答

- **条件:** 用户要求解释、审查、比较、展示信息或其他只读分析。
- **动作:** 读取必要上下文后直接回答，不创建方案包，不修改代码或知识库。

### 系统化调试

- **条件:** 用户报告 Bug、测试/构建失败、运行异常、性能回退、flaky/超时、错误日志、stack trace 或回归问题。
- **共同诊断门禁:** 读取完整错误，稳定复现或记录无法复现的证据，检查近期变更与环境差异，定位失败层级，沿数据流追踪坏状态来源，每次只验证一个根因假设。
- **多组件问题:** 在每个边界记录输入、输出和配置传播；污染问题定位 polluter；异步问题等待真实条件，不用固定 sleep 掩盖根因。

诊断后按以下出口处理:

#### 普通缺陷直接实施

- 用户明确要求修复，且 `风险等级=低` 或 `风险等级=中`、`EHRB=无`、无破坏性公共契约和真实数据迁移。
- 根因确认后直接进入 develop 的自适应开发入口，先补能复现问题的测试，再做最小修复和验证。
- 不强制创建方案包，不要求第二次确认；中风险或跨模块修复可按审计需要保留简化 `task.md`。

#### 只读诊断

- 用户只要求定位/解释，或当前证据不足以安全修改。
- 仅执行复现、根因调查和最小验证；需要用户提供环境、日志或复现条件时先澄清。

#### 高风险升级

- 根因要求架构变更、破坏性公共契约、真实数据迁移、生产操作或其他 EHRB，或连续 3 次修复假设失败。
- 停止扩大改动，进入完整研发并在写入前确认。

### 微调模式

- **条件:** 改动授权明确、`风险等级=低`、无可观察行为/API/配置语义变化、无 EHRB。
- **典型场景:** 文档勘误、注释修正、格式整理、测试内局部重命名、机械示例更新。
- **动作:** 直接最小修改，执行相关静态/格式/安全验证。
- **产物:** 不创建方案包或 QA JSON；仅当稳定项目知识发生变化时更新对应文档。
- **说明:** 文件数量和行数只影响读取与验证策略，不作为硬阈值。

### 轻量迭代

#### 低风险小改动直接实施

- **条件:** 用户明确要求修改，需求清晰，本地可逆，无外部副作用、破坏性公共契约、数据迁移和 EHRB。
- **动作:** 获取最小上下文，按需执行 TDD，实施改动，运行目标验证和安全核对后直接总结。
- **产物:** 默认不创建方案包；仅在公共行为或稳定约定变化时同步相应知识库，发布相关变化才更新 CHANGELOG。

#### 中风险小改动连续实施

- **条件:** 需求和边界明确，存在可回滚的行为或跨模块变化，公共契约保持兼容，`EHRB=无`。
- **动作:** 先形成简短内部计划和成功标准，再按 TDD/替代验证连续实施；无需第二次确认。
- **产物:** 多步骤、跨模块或需要恢复执行时可创建仅含 `task.md` 的轻量方案包，否则在最终摘要记录验证证据。

轻量迭代不再由固定文件数量定义。发现架构决策、破坏性契约、真实数据迁移或关键不确定性时升级为完整研发。

### 标准开发

- **条件:** `风险等级=中`，需求明确，涉及多个协调任务或模块，但无架构级决策、破坏性公共契约、真实数据迁移和 EHRB。
- **动作:** 完成轻量需求分析，形成可执行任务和验证策略；用户已明确授权改动时连续进入实施，不以阶段总结重复请求确认。
- **产物:** 根据可恢复性和审计需要选择轻量 `task.md` 或完整方案包；存在方案包时按 develop/qa/lifecycle 处理。
- **升级:** 范围扩大为高风险或关键目标不明确时停止实施并进入完整研发。

### 完整研发

- **条件:** `风险等级=高`，包括需求/影响高度不确定、架构或技术选型、新模块边界、破坏性公共契约、真实数据迁移、生产操作或 EHRB。
- **动作:** 需求分析 → 方案设计 → 创建完整方案包；写入业务代码或执行副作用前等待明确确认。
- **命令边界:** `~plan` 到方案包后停止；`~auto` 可连续推进普通步骤，但不能绕过 EHRB 确认；`~exec` 执行用户选定的合法方案包。

### 开发实施入口门禁

以下任一条件允许进入相应开发实施路径:

```yaml
1. 当前会话已创建合法方案包，用户明确确认进入开发实施
2. ~auto 已授权且 AUTH_WORKFLOW_ID=WORKFLOW_ID；EHRB 仍需单独确认
3. ~exec 已授权、存在合法完整或轻量方案包，且 AUTH_WORKFLOW_ID=WORKFLOW_ID
4. 用户明确要求修复/修改/实现，风险等级为低或中，EHRB=无，无破坏性公共契约或真实数据迁移
```

第 4 项是自适应开发授权，不要求先创建方案包或使用特殊命令。只读请求、高风险操作和需求不明确场景不得使用该入口。
