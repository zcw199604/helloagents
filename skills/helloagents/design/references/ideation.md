# 方案构思规则

## 方案构思

### 动作步骤

**1. 检查知识库状态并处理**
- 只检查本次设计所需的既有知识；缺失不阻断设计，不自动重建。
- 需要知识库规则时读取 [kb](../../kb/SKILL.md)，创建或更新须通过写入收益门禁。

**2. 读取知识库**
- 复用相关知识和已有分析，不足则定向搜索代码、配置和测试。
- 如需详细规则 → 读取 `kb` Skill

**3. 判定项目规模**
- 根据模块边界、依赖、受影响契约和故障成本评估规模，文件数只用于估算读取与验证成本。

**4. 判定需求类型并选择模板**
- 技术变更: 使用基础模板。
- 产品功能且使用者、场景或成功指标影响方案选择: 增加产品分析章节。

**5. 产品视角分析（步骤4判定为"产品功能"时执行）**
- 用户画像、场景分析、痛点分析
- 价值主张、成功指标
- 人文关怀考量

**6. 任务复杂度判定**

满足任一条件为复杂任务:
```yaml
- 需求属于"新项目初始化"或"重大功能重构"
- 涉及架构决策
- 涉及技术选型
- 可行路径之间存在会改变架构、公共行为、兼容性或运行成本的实质取舍
- 跨模块契约尚未明确，或存在无法独立验证的高耦合变化
- 用户明确要求多方案
```

文件多、存在多个写法或启用协作不单独触发复杂任务；边界明确的跨文件机械调整直接采用已知方案。

**6.5 大范围方案拆分**

```yaml
触发条件: 需求分析标记为大范围需求，或方案构思时发现无法在单个可验证闭环内完成
拆分原则:
  - 按业务能力、模块边界、风险等级或可交付闭环拆分
  - 每个切片必须可独立验证、可独立回滚、可独立记录知识库
  - 一个闭环可在同一方案包中按切片分组；独立交付且需单独恢复时再拆为多个方案包
  - 用户已授权的全部切片仍属于交付范围，不得自行降为后续计划
交互确认模式或 MODE_PLANNING_INTERACTIVE=true: 如当前切片未明确，输出方案构思选择，让用户选择先执行哪一片
推进模式（不含交互式规划）: 按依赖与风险排序连续完成全部已授权切片；优先级影响业务结果或授权边界时才追问
```

**7. 方案构思**

<solution_design>
**方案评估标准:**
- 优点
- 缺点
- 性能影响
- 可维护性
- 实现复杂度
- 风险评估（含EHRB）
- 成本估算
- 是否符合最佳实践
- 大型项目最小改动: 优先局部修复、兼容适配和渐进式演进；完整重构必须有明确必要性和风险缓解

只比较会改变决策的可行路径，说明推荐依据；不穷举技术写法或为凑数量构造较差方案。

**基于推理结果执行：**

**复杂任务（强制方案对比）:**
- 生成 2-3 个可行方案
- 详细评估每个方案
- 确定推荐方案和理由
- 输出格式: 推荐方案标题后加"推荐"标识
  - 例: "方案1（最小变更修复-推荐）" vs "方案2（完整重构）"
- 交互确认模式或 MODE_PLANNING_INTERACTIVE=true: 设置 `PENDING_INTERACTION=SOLUTION_CHOICE`，输出方案对比并询问用户选择
- 推进模式（不含交互式规划）: 选择推荐方案（不输出对比）

**简单任务:**
- 直接确定唯一可行方案
- 简要说明方案
</solution_design>

### 方案构思 输出格式（等待用户选择方案时）

行首: `❓【HelloAGENTS】- 方案构思`

**输出内容(≤5条要点):**
```
❓【HelloAGENTS】- 方案构思

- 📚 上下文: [项目规模] | [知识库状态]
- 📋 需求类型: [技术变更/产品功能]
- 🔍 复杂度: [复杂任务] - [判定依据]
- 💡 方案对比:
  - 方案1: [名称-推荐] - [一句话说明]
  - 方案2: [名称] - [一句话说明]
- ⚠️ 风险提示: [如有EHRB或重大风险]

────
🔄 下一步: 请输入方案序号(1/2/3)选择方案
```

**详细方案说明:** 如用户需要详细对比，可追问后展开

### 方案构思 子阶段转换

```yaml
复杂任务:
  交互确认模式或 MODE_PLANNING_INTERACTIVE=true:
    - 用户选择有效序号(1-N) → 进入详细规划
    - 用户拒绝所有方案 → 输出重新构思询问格式
      - 确认重新构思: 返回方案构思，重新构思
      - 拒绝: 执行 RESET_WORKFLOW_STATE，提示"已取消方案设计"，流程终止
      - 其他输入: 再次询问
  推进模式（不含交互式规划）:
    - 选择推荐方案 → 立即静默进入详细规划

简单任务: 直接进入详细规划
```

**重新构思方案询问格式:**

输出前设置 `PENDING_INTERACTION=SOLUTION_REDESIGN`。
```
❓【HelloAGENTS】- 方案确认

所有方案均被拒绝。

[1] 重新构思 - 基于反馈重新设计方案
[2] 取消 - 终止方案设计

────
🔄 下一步: 请输入序号选择
```
