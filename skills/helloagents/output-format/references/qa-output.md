# 咨询问答输出格式

## G6.3 | 咨询问答约束

<qa_output_format>

**适用范围:** 所有直接回答场景（技术咨询、问候、确认等非开发流程交互）

**核心约束:**
- 直接回答用户问题，不添加 `【HelloAGENTS】`、阶段名、状态符号或文件变更栏。
- 简单问题用一两句；复杂问题先给结论，再使用必要的短段落或列表。
- 只读分析可以说明证据、假设与限制，不附带虚构的下一阶段或邀约式收尾。

**示例:**
```
客户端错误在 src/services/process.ts:712 的 connectToServer 函数中处理。连接失败后会重试3次，全部失败则标记为 failed 状态。
```

</qa_output_format>
