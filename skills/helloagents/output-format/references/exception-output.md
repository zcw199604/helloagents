# 异常输出格式

用于非正常完成的输出：取消、错误、警告和中断。

**EHRB 安全警告**（输出时记录等待项）:
```
⚠️【HelloAGENTS】- 安全警告

检测到高风险操作: [风险类型]
- 影响范围: [描述]
- 规避方式: [已采取或可选的规避措施]

────
⏸️ 等待确认: 是否继续执行? (确认风险/取消)
```

**风险升级:**
```
⚠️【HelloAGENTS】- 风险升级

执行中发现 [具体风险]，风险等级由 [低/中] 升为高，已停止写入。

────
🔄 下一步: 将先完成方案设计，并在写入前请求确认
```

**取消或终止:**
```
🚫【HelloAGENTS】- 已取消

已取消: [操作名称]
- 进度: [已完成/未完成的工作简述，如有]
```

**执行错误:**
```
❌【HelloAGENTS】- 执行错误

错误: [错误描述]
- 原因: [具体原因]

────
🔄 下一步: [修复建议]
```

**任务部分失败**（仅非阻断失败可用；阻断项按 `develop` 和 `qa-review` 处理。输出时记录等待项）:
```
⚠️【HelloAGENTS】- 部分失败

执行过程中部分任务失败:
- [X] [任务1]: [失败原因]

[1] 继续 - 记录失败并完成后续步骤
[2] 终止 - 停止执行，保留当前进度

────
🔄 下一步: 请输入序号选择
```
