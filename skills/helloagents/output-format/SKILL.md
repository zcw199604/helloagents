# 输出格式

**目标:** 让输出服务于结果交付，只在结构确实提高可读性或承载交互状态时使用模板。

---

## 输出类型选择

| 输出场景 | 状态符号 | 读取文件 |
|---|---|---|
| 阶段完成、代码/文档改动完成 | ✅ / ⚠️ | `references/unified-output.md` |
| 错误、取消、安全警告、部分失败 | ❌ / 🚫 / ⚠️ | `references/exception-output.md` |
| 技术咨询、概念解释、只读分析 | 无固定符号 | `references/qa-output.md` |
| 需要用户选择或确认 | ❓ / ⚠️ | `references/interactive-output.md` |
| `~auto` / `~plan` / `~exec` / `~init` 命令完成 | ✅ | `references/command-output.md` |

---

## 包装门禁

- 普通咨询与简短确认不使用阶段包装，直接回答问题；不输出阶段名、评分、文件清单或“下一阶段”。
- 自适应低/中风险路径中的分析、内部设计和阶段转换默认静默连续执行，不逐阶段输出总结。
- 正式命令完成、需要用户选择、异常和高风险确认使用对应模板并包含 `【HelloAGENTS】`。
- 写入完成必须说明结果、关键文件、实际验证和剩余风险，但允许用自然段或短列表表达，不强制固定栏目。
- 文件较多时才使用纵向清单；无变更的只读回答无需声明 `📁 变更: 无`。
- 其他 skill 不复制完整模板，只引用本 skill 的输出类型和填充字段。

---

## 正反例

**应使用模板:**
- 开发实施完成，需要列出变更文件和验证结果。
- 命令执行失败，需要按异常模板说明原因。
- 高风险确认或多选交互，需要稳定选项和等待态。

**不应使用模板:**
- 中间进度更新；使用简短自然语言即可。
- 内部推理或工具调用摘要；不输出模板。
- 普通咨询、简单确认和自适应路径的中间阶段。

---

## 完成门禁

- 使用模板时单次用户可见消息只有一个主模板；交互区块必须设置对应 `PENDING_INTERACTION`。
- 输出状态符号与场景匹配。
- 正式交付说明结果、关键文件、验证结果和剩余风险；没有真实下一步时不添加邀约式建议。
- 未把模板原文泄露为无关长篇内容。
