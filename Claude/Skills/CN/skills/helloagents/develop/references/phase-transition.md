# 开发实施阶段转换规则

## 阶段转换规则

```yaml
完成所有动作后（步骤12迁移完成）:
  交互确认模式 / 执行命令:
    - 执行步骤13多模型验收询问
    - 用户选择 [1] → 读取 multi_model Skill 执行验收 → 输出验收报告 → 输出完成总结
    - 用户选择 [2] → 直接输出完成总结 → 开发实施结束
  全授权命令:
    - 跳过步骤13询问 → 输出整体总结（末尾含多模型验收提示） → 流程结束
  变量清理: CURRENT_PACKAGE 将在遗留方案扫描时自动清理（按 lifecycle Skill 的 G11 规则）

异常情况（测试失败/用户提出问题）:
  阻断性测试失败: 所有模式均立即停止，按步骤7阻断性测试失败格式等待用户决策
  警告性/信息性测试失败:
    - 交互确认模式: 在输出中标注，等待用户决定
    - 全授权命令/执行命令: 在总结中标注测试失败，流程正常结束
  后续用户消息按路由优先级处理
```
