# 统一输出格式

用于正式命令完成和方案包交付。高风险或多步骤交付在固定结构能明显提高可核查性时也可使用。

## 渲染结构

```
{状态符号}【HelloAGENTS】- {名称}

[≤5 条结构化要点]

────
📁 变更:
  - {文件路径1}
  - {文件路径2}
  ...

🔄 下一步: [≤2 句；没有真实下一步时省略]

[📦 遗留方案: 存在时显示]
```

**状态符号:**
- ✅ 成功完成
- ❓ 等待用户输入或选择
- ⚠️ 警告、部分失败或需要用户决策
- 🚫 已取消
- ❌ 严重错误

**名称:** 方案设计、开发实施，或“全授权命令完成 / 规划命令完成 / 执行命令完成 / 知识库命令完成”。

## 清单

只有一两个文件时可在正文说明，不必列清单。

```
📁 变更:
  - {文件路径}
  ...

📦 遗留方案: 检测到 X 个未执行的方案包:
  - {方案包名称}
  ...
可使用 ~exec 选择执行；如确认不再执行，可明确请求标记为取消后归档。
```

遗留方案按 `lifecycle` 扫描，只在存在遗留项时显示，位于输出末尾。

## 语言

自然语言遵循用户和项目当前的语言约定，标识符与专有名词保持原样。
