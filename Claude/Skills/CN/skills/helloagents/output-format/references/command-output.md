# 命令完成输出

均遵循统一输出格式，以下是各命令的要点内容。只填写实际发生的内容，未发生的行省略。

**全授权命令完成:**
```
✅【HelloAGENTS】- 全授权命令完成

- ✅ 执行路径: 需求分析 → 方案设计 → 开发实施
- 📊 执行结果: 任务 Y/Z 完成
- 🔍 质量验证: [测试结果摘要]
- 💡 关键决策: [决策摘要，如有]

────
📁 变更:
  - {代码文件}
  - {知识库文件}
  - helloagents/<branch-name>/history/...
  ...

📦 遗留方案: [如有]
```

**规划命令完成:**
```
✅【HelloAGENTS】- 规划命令完成

- 📋 需求: [关键目标与成功标准]
- 📝 方案: [方案概要], 任务数 X
- ⚠️ 风险: [如有]

────
📁 变更:
  - helloagents/<branch-name>/plan/{方案包目录}/...
  - {规划期间实际更新的知识库文件，如有}

🔄 下一步: 如需执行请输入 ~exec
📦 遗留方案: [如有]
```

**执行命令完成:**
```
✅【HelloAGENTS】- 执行命令完成

- ✅ 执行方案: [方案包名称]
- 📊 执行结果: 任务 Y/Z 完成
- 🔍 质量验证: [测试结果摘要]

────
📁 变更:
  - {代码文件}
  - {知识库文件}
  - helloagents/<branch-name>/history/...
  ...

📦 遗留方案: [如有]
```

**知识库命令完成:**
```
✅【HelloAGENTS】- 知识库命令完成

- 📚 知识库状态: [已创建/已更新/已重建]
- 📊 操作摘要: 扫描 X 个模块, 创建/更新 Y 个文档
- 🔍 质量检查: [发现的问题，如有]

────
📁 变更:
  - {知识库文件}
  ...
```

**测试命令:** 不使用模板，按低/中风险改动完成摘要说明测试范围、TDD 决策或 TDD-EXEMPT 原因、测试命令与结果。
